계정과 데이터

가입하지 않아도 앱을 사용할 수 있습니다. 재설치하거나 기기를 변경해도 데이터를 이어서 사용하려면 이메일·Google·Apple 계정을 연결해 로그인하세요. 소셜 로그인은 캘린더 접근 권한을 요청하지 않습니다.

계정 삭제는 앱의 더보기 → 계정 관리 → 계정 삭제에서 직접 진행할 수 있습니다.

자주 묻는 질문

외부 캘린더 일정도 공유되나요?

아니요. 사용자가 허용한 기기 캘린더는 해당 기기에서 읽기 전용으로만 표시되며 TimeFlower 서버나 다른 구성원에게 전송되지 않습니다.

앱을 삭제하면 데이터도 바로 삭제되나요?

앱 삭제만으로 서버 데이터가 삭제되지는 않습니다. 계정을 만들었다면 앱 안의 계정 삭제 기능을 사용해 주세요. 가입하지 않은 게스트 데이터는 앱 삭제 후 다시 접근할 수 없습니다.

광고나 사용자 추적을 하나요?

TimeFlower는 광고를 제공하지 않고 다른 회사의 앱이나 웹사이트를 가로지르는 사용자 추적을 하지 않습니다.
