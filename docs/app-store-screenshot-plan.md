# TimeLine App Store 스크린샷 계획

## 규격

- 기본 세트: iPhone 6.9형 세로 `1290 × 2796 px`
- 파일 형식: PNG
- 알파 채널 없음
- 한국어 세트 6장
- 화면에 실제로 제공되는 기능만 사용
- 실명, 이메일, 실제 초대 코드 등 개인정보를 사용하지 않음

Apple이 허용하는 6.9형 규격에는 `1260 × 2736`, `1290 × 2796`,
`1320 × 2868`이 있다. 이 프로젝트는 `1290 × 2796`으로 통일한다.

## 데모 데이터

- 사용자: 지우
- 캘린더:
  - 우리 집 — 살구색
  - 둘의 약속 — 쪽빛
  - 주말 모임 — 초록색
- 일정:
  - 가족 저녁 식사 / 오늘 19:00 / 우리 집
  - 치과 예약 / 오늘 14:30 / 연세치과
  - 주간 장보기 / 토요일 11:00 / 매주 반복
  - 제주 여행 / 3일간 종일
  - 영화 보는 날 / 금요일 20:00 / 참여자 2명, 댓글 3개

## 컷 구성

### 1. 함께 보는 한 달

- 화면: 홈 월간 캘린더
- 헤드라인: `우리의 일정을 한눈에`
- 보조 문구: `여러 캘린더를 색상별로 모아보세요`
- 강조 요소: 월간 격자, 캘린더 필터, 선택한 날짜 일정

### 2. 반복되는 일정도 간단하게

- 화면: 일정 작성
- 헤드라인: `한 번 만들고 계속 이어지게`
- 보조 문구: `매일·매주·매월·매년 반복을 지원해요`
- 강조 요소: 종일 여부, 날짜와 시각, 반복 옵션

### 3. 초대 링크 하나로 공유

- 화면: 캘린더 관리
- 헤드라인: `가까운 사람과 함께`
- 보조 문구: `링크를 보내 같은 캘린더를 시작하세요`
- 강조 요소: 구성원, 초대 링크 생성, 색상 설정

### 4. 일정마다 이어지는 대화

- 화면: 일정 상세
- 헤드라인: `약속에 필요한 이야기도 한곳에`
- 보조 문구: `참여자를 정하고 댓글로 준비하세요`
- 강조 요소: 참여자, 댓글 스레드, 미리 알림

### 5. 바뀐 내용을 놓치지 않게

- 화면: 활동
- 헤드라인: `누가 무엇을 바꿨는지`
- 보조 문구: `변경 내역에서 일정으로 바로 이동하세요`
- 강조 요소: 날짜별 활동 목록, 작성자와 변경 요약

### 6. 내 취향에 맞는 분위기

- 화면: 설정의 테마 선택
- 헤드라인: `살구·쪽빛·먹빛`
- 보조 문구: `사람마다 원하는 테마를 고를 수 있어요`
- 강조 요소: 세 가지 테마 옵션

## 캡처 절차

1. TestFlight 빌드를 실제 iPhone에 설치한다.
2. 테스트용 계정과 위 데모 데이터를 만든다.
3. 알림, 배터리, 통신사 등 상태 표시줄에 개인정보가 없는지 확인한다.
4. 각 화면에서 필요한 요소가 스크롤 없이 보이게 준비한다.
5. 기기 원본 스크린샷을 촬영한다.
6. `1290 × 2796 px` 캔버스에 헤드라인과 보조 문구를 배치한다.
7. PNG를 RGB로 내보내고 알파 채널이 없는지 검사한다.
8. App Store Connect 업로드 전에 축소 화면에서도 문구가 읽히는지 검수한다.
