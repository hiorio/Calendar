### 설명

TimeFlower는 가까운 사람들과 일정을 함께 관리하는 공유 캘린더입니다.

가입하지 않아도 바로 개인 캘린더를 시작할 수 있습니다. 앱을 다시 설치하거나 기기를 변경해도 데이터를 이어서 사용하려면 이메일 계정을 만들어 로그인할 수 있습니다.

주요 기능

- 한눈에 보는 월간 캘린더
  여러 캘린더의 일정을 색상별로 확인하고, 원하는 캘린더만 골라 볼 수 있습니다.

- 자유로운 일정 관리
  종일 일정과 시간 일정, 장소, 메모, 첨부 파일을 기록할 수 있습니다. 매일·매주·매월·매년 반복 일정과 특정 회차의 수정·삭제를 지원합니다.

- 초대 링크로 간편한 공유
  캘린더 초대 링크를 보내 가족, 연인, 친구, 모임 구성원과 같은 일정을 관리할 수 있습니다.

- 일정별 소통과 기록
  일정마다 참여 여부와 댓글을 남기고, 누가 무엇을 변경했는지 활동 이력에서 확인할 수 있습니다.

- 필요한 알림만 선택
  캘린더별 알림을 끄거나 일정 전에 미리 알림을 설정할 수 있습니다.

- 취향에 맞는 화면
  살구·쪽빛·먹빛 테마, 다크·라이트 모드, 글꼴과 글자 크기를 선택할 수 있습니다.

TimeFlower와 함께 흩어진 약속을 하나의 흐름으로 정리해 보세요.

## App Review 메모 — 한국어

TimeFlower는 첫 실행 시 Supabase 익명 세션을 자동 생성합니다. 별도의 계정이나 로그인 없이 주요 기능을 확인할 수 있습니다.

권장 심사 순서:

1. 첫 화면에서 월간 캘린더를 확인합니다.
2. 하단 추가 탭 또는 날짜를 선택한 뒤 `+` 버튼을 눌러 일정을 만듭니다.
3. 일정 상세 화면에서 반복, 참여 여부, 댓글, 미리 알림을 확인합니다.
4. 활동 탭에서 일정 생성·수정 기록을 확인합니다.
5. 더보기/설정에서 테마, 화면 모드, 글꼴, 글자 크기와 앱 내 계정 삭제 진입점을 확인합니다.

가입은 필수가 아닙니다. 앱 재설치 또는 기기 변경 후에도 데이터를 이어서 사용하거나 공유 캘린더를 사용하려는 경우에만 이메일 계정을 만들 수 있습니다. 이 버전은 Google 로그인 및 Apple 로그인을 제공하지 않습니다.

계정 삭제는 앱의 `더보기 > 계정 관리 > 계정 삭제`에서 앱을 벗어나지 않고 수행할 수 있습니다. 삭제 전에 단독 소유 캘린더의 삭제, 공유 캘린더의 소유권 이전, 다른 캘린더에서의 탈퇴 결과를 안내합니다. 남은 공유 구성원이 계속 사용해야 하는 일정과 댓글은 작성자의 식별 프로필을 제거한 뒤 유지될 수 있습니다.

외부 기기 캘린더 보기는 사용자가 기능을 직접 켜고 iOS 캘린더 접근을 허용한 경우에만 동작하는 선택 기능입니다. 외부 일정은 기기에서 읽기 전용으로 표시되며 TimeFlower 서버에 업로드하거나 다른 구성원에게 공유하지 않고, 원본 기기 캘린더도 수정하지 않습니다. Google 또는 Apple 계정에 직접 로그인하는 방식의 캘린더 연동은 제공하지 않습니다.

인앱 결제, 구독, 광고 및 사용자 추적은 없습니다.

## App Review Notes — English

TimeFlower automatically creates a Supabase anonymous session on first launch, so reviewers can test the main features without credentials or a demo account.

Suggested review flow:

1. Open the monthly calendar on the first screen.
2. Use the Add tab, or select a date and tap the `+` button, to create an event.
3. Open an event to review recurrence, attendance, comments, and reminders.
4. Open the Activity tab to review event creation and edit history.
5. Open More/Settings to review themes, appearance, fonts, text size, and the in-app account deletion entry point.

Registration is optional. Users may create an email account only when they want to preserve data after reinstalling or changing devices, or when they need shared-calendar features. Google Sign-In and Sign in with Apple are not offered in this version.

Account deletion is available inside the app at `More > Account management > Delete account`. Before deletion, the app explains which sole-member calendars will be deleted, which shared calendars will transfer ownership, and which calendars the user will leave. Content required by remaining shared-calendar members may remain after the author's identifying profile is removed.

External device calendars are an optional read-only feature. They are shown only after the user enables the feature and grants iOS calendar access. External events remain local to the device, are not uploaded to TimeFlower or shared with other members, and the app does not modify the source calendar. Direct Google or Apple account calendar integration is not offered.

There are no in-app purchases, subscriptions, advertisements, or user tracking.

## App Privacy 응답 초안

현재 production 설정과 구현을 기준으로 한다. 기능, SDK 또는 운영 설정이 바뀌면 다시 검토한다.

| 데이터 유형 | 수집 | 사용자 연결 | 추적 | 목적 |
|---|---:|---:|---:|---|
| 사용자 ID | 예 | 예 | 아니요 | 앱 기능, 계정 관리 |
| 이름 또는 닉네임 | 예 | 예 | 아니요 | 앱 기능 |
| 이메일 주소 | 계정 생성 시 | 예 | 아니요 | 인증, 계정 관리 |
| 사용자 콘텐츠(캘린더·일정·메모·댓글·첨부 파일) | 예 | 예 | 아니요 | 앱 기능 |
| 푸시 토큰 | 알림 활성화 시 | 예 | 아니요 | 앱 기능 |
| 충돌·성능 진단 | Sentry 활성화 시 | 예 또는 익명 | 아니요 | 분석, 앱 기능 |

production 환경은 현재 Sentry 원격 전송이 비활성화되어 있다. 활성화 전에 App Privacy 응답과 개인정보 처리방침을 실제 전송 데이터에 맞게 갱신한다.

현재 수집하지 않는 항목:

- 결제 정보
- 정밀 또는 대략적 위치
- 주소록
- 건강 및 피트니스 정보
- 검색 또는 브라우징 기록
- 광고 데이터
- 다른 회사의 앱·웹사이트를 가로지르는 사용자 추적

## 수출 규정

앱은 운영체제와 HTTPS 통신이 제공하는 표준 암호화만 사용하고 자체 암호화 알고리즘을 구현하지 않는다. Expo 설정의 `ios.config.usesNonExemptEncryption`은 `false`이다. App Store Connect의 최신 질문 문구와 실제 기능을 확인해 답변한다.

## 제출 전 확인

- 새 `production` TestFlight 빌드에서 앱 이름이 `TimeFlower`이고 새 꽃 아이콘이 표시되는지 확인
- 로그인 없이 첫 실행하고 월간 캘린더가 바로 표시되는지 확인
- 캘린더·일정 생성, 수정, 삭제 확인
- 반복 일정의 회차 수정·삭제 확인
- 계정 생성, 로그인, 로그아웃, 계정 삭제 확인
- 서로 다른 두 계정으로 초대 링크, 권한 분리, 다른 사용자의 비공개 데이터가 보이지 않는지 확인
- 외부 캘린더 권한을 거부했을 때와 허용했을 때 모두 확인
- 백엔드와 Edge Function이 심사 기간 동안 계속 동작하는지 확인
- 스크린샷에 테스트 이메일, 초대 코드, 실명 등 개인정보가 노출되지 않는지 확인
- 개인정보 처리방침 및 지원 URL이 공개 HTTPS로 열리는지 확인
- App Privacy 응답이 실제 production 환경과 일치하는지 확인
- 원격 푸시를 광고한다면 실제 기기에서 수신까지 확인
