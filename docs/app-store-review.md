## 제품 페이지

### 앱 이름

TimeLine

### 부제

함께 만드는 공유 캘린더

### 홍보 문구

가족, 연인, 친구와 일정을 한곳에서 나누세요. 반복 일정부터 댓글과 활동 내역까지, 함께 정리하는 시간이 더 간단해집니다.

### 설명

TimeLine은 가까운 사람들과 일정을 함께 관리하는 공유 캘린더입니다.

가입하기 전에도 바로 개인 캘린더를 시작할 수 있습니다. 공유가 필요해지면 계정을 연결해 지금까지 만든 일정을 그대로 이어가세요.

주요 기능

• 한눈에 보는 월간 캘린더
여러 캘린더의 일정을 색상별로 확인하고, 보고 싶은 캘린더만 골라 표시할 수 있습니다.

• 자유로운 일정 관리
종일 일정과 시간 지정 일정, 장소와 메모를 기록할 수 있습니다. 매일·매주·매월·매년 반복되는 일정과 특정 회차 수정·삭제도 지원합니다.

• 초대 링크로 간편한 공유
캘린더를 만든 뒤 초대 링크를 보내면 가족, 연인, 친구, 모임 구성원이 같은 일정을 함께 관리할 수 있습니다.

• 일정마다 이어지는 대화
일정별 참여자를 지정하고 댓글을 남겨 약속에 필요한 이야기를 한곳에 모을 수 있습니다.

• 변경 사항을 보여주는 활동 내역
누가 일정을 만들고 바꾸었는지 시간순으로 확인하고 관련 일정으로 바로 이동할 수 있습니다.

• 필요한 알림만 선택
캘린더별 알림을 끄거나 일정별 미리 알림을 설정할 수 있습니다.

• 취향에 맞는 화면
살구, 쪽빛, 먹빛 테마 중 원하는 분위기를 기기별로 선택할 수 있습니다.

TimeLine과 함께 흩어진 약속을 하나의 흐름으로 정리해 보세요.

## App Review 메모 — 한국어

TimeLine은 앱을 실행하면 Supabase 익명 세션을 자동으로 생성하므로 별도의 데모 계정이나
로그인 없이 주요 기능을 확인할 수 있습니다.

테스트 순서:

1. 첫 화면에서 ‘캘린더 만들기’를 눌러 캘린더를 만듭니다.
2. 하단 ‘추가’ 탭 또는 선택한 날짜의 ‘추가’를 눌러 일정을 만듭니다.
3. 일정 상세 화면에서 반복, 참여자, 댓글, 미리 알림을 확인합니다.
4. ‘활동’ 탭에서 생성·수정 기록을 확인합니다.
5. ‘설정’에서 테마와 계정 삭제 진입점을 확인합니다.

초대 링크 생성과 공유 캘린더 참여는 데이터의 기기 간 연속성이 필요하여 정식 계정으로
전환한 뒤 사용할 수 있습니다. 게스트가 이메일 또는 소셜 계정을 연결하면 기존 데이터의
사용자 ID가 유지됩니다.

계정 삭제는 설정 > 계정 삭제에서 앱을 벗어나지 않고 수행할 수 있습니다. 삭제 전에
혼자 소유한 캘린더의 삭제, 공유 캘린더의 소유권 이전, 다른 캘린더 탈퇴 결과를 미리
보여 줍니다. 공유 구성원이 계속 사용해야 하는 일정과 댓글은 작성자 식별 정보를 제거한
뒤 남을 수 있습니다.

기기 캘린더 가져오기는 현재 사용자 화면에 노출하지 않은 후속 기능이며, 이번 버전의
제품 설명에는 포함하지 않았습니다. 앱은 기기 캘린더를 수정하지 않습니다.

앱 내 구입, 구독, 광고, 사용자 추적은 없습니다.

## App Review Notes — English

TimeLine automatically creates a Supabase anonymous session on first launch, so the reviewer can
test the main functionality without credentials or a demo account.

Suggested review flow:

1. Tap “캘린더 만들기” to create a calendar.
2. Use the Add tab or the Add button for a selected date to create an event.
3. Open an event to review recurrence, participants, comments, and reminders.
4. Open the Activity tab to review the event history.
5. Open Settings to review theme selection and the in-app account deletion entry point.

Creating invitation links and joining a shared calendar require upgrading the guest session to a
permanent account so shared data can continue across devices. Linking an email or social account
keeps the guest user ID and existing data.

Account deletion is available inside the app at Settings > Account deletion. Before deletion, the
app explains which sole-member calendars will be deleted, which shared calendars will transfer
ownership, and which calendars the user will leave. Content needed by remaining shared-calendar
members may remain after the author's identifying profile is removed.

Device-calendar import is not exposed in this version and is not advertised in the product
description. The app does not modify the device calendar.

There are no in-app purchases, subscriptions, advertisements, or user tracking.

| 이름(닉네임) | 예 | 예 | 아니요 | 앱 기능 |

현재 production 환경은 Sentry와 원격 푸시 등록이 비활성화되어 있다. 활성화 전에 App

## 수출 규정

앱은 운영체제와 HTTPS 통신이 제공하는 표준 암호화만 사용하고 자체 암호화 알고리즘을
구현하지 않는다. Expo 설정의 `ios.config.usesNonExemptEncryption`은 `false`이다.
App Store Connect 질문에는 실제 기능과 Apple의 최신 정의를 다시 확인해 답한다.
